# Memory Directory Documentation

## \ud83d\udcc2 logs
Здесь хранятся журналы событий и фаз развития LAM.

- `history_phase_1.log`: запись ключевых событий первой фазы.

## \ud83d\udcc2 metadata
Файлы с мета-информацией для конфигурации и якорей памяти LAM.

- `anchor_memory_phase.json`: опорные точки и ключевые метаданные для фаз памяти.

## \ud83d\udcc2 data
Здесь хранятся файлы с данными памяти.

- `memory_items.json`: структурированные записи элементов памяти.

## Правила добавления новых файлов
- Логи помещаются в каталог `logs`, с чёткими названиями, отражающими фазы или события.
- Мета-информация должна быть описана и сохранена в `metadata`.
- Данные памяти размещаются в каталоге `data` в формате JSON с ясной структурой.
